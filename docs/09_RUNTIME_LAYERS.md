# Calques runtime — composition consolidée

L’ordre validé de composition est :

1. extérieur complet ;
2. architecture transparente du Pavillon ;
3. posture PNG de TAO ;
4. bureau maître canonique ;
5. conteneur des objets variables ;
6. dialogue, navigation et panneaux techniques.

`BUREAU_BASE_CARTE_CELESTE.png` reste permanent. L’extérieur utilise `object-fit: contain` et reste centré.

## Limite de validation

La structure des calques porte la correction de scène validée. `exterior-states.js` constitue l’Étape 9 techniquement terminée, en attente de validation utilisateur. `desk-objects.js` constitue désormais l’Étape 8 techniquement terminée avec validation visuelle des assets en cours : 11 objets sont disponibles manuellement et sept extractions de classe C restent exclues du runtime.

Ils n’activent aucune automatisation et leurs changements temporaires ne sont pas enregistrés.
